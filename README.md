# 🏷️ DynamicNameplates
*A smarter, cleaner way to render player nameplates in Minecraft.*

![DynamicNameplates Logo](https://github.com/Adelemphii/DynamicNameplates/blob/master/src/main/resources/assets/dynamicnameplates/icon.png)

---

## ✨ Overview
**DynamicNameplates** gives you full control over how player nameplates appear and when they’re visible.  
Instead of cluttering your screen with floating text at all times, this mod makes nameplates feel natural — only showing them when you’re looking at a player, nearby, or within a custom detection area.

---

## Features
- **Custom Rendering Modes**
  - **Crosshair Mode** – Nameplates show only when you’re looking directly at a player.  
  - **Cube Mode** – Shows nameplates when the player is inside a tolerance box that scales with distance.  
  - **Area Mode** – Simple range-based visibility — see nameplates within a chosen radius.

- **Configurable Behavior**
  - Separate *close range* and *long range* modes.
  - Adjustable thresholds for angle and distance.
  - Option to hold a key to temporarily show nameplates.

- **ModMenu Integration**
  - Change settings directly from the in-game menu using `owo-config`.
